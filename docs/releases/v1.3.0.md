# XCC Context Collector v1.3.0

Version: 1.3.0
Release date: 2026-07-30

## Summary

XCC v1.3.0 turns Selected Files into a direct AI-to-context workflow. A file list returned by ChatGPT, Codex, Claude, or another assistant can be copied, pasted into XCC, resolved against a visible project root, reviewed, and collected without selecting every file manually.

The release is intentionally focused. It preserves the v1.2.0 fidelity, Git, budgeting, safety, background-worker, Windows integration, and release-engineering baseline while removing friction from repeated AI coding sessions.

## Highlights

### Paste file lists from AI responses

Selected Files now exposes **Paste Paths** and supports guarded `Ctrl+V`. The parser accepts:

- plain one-path-per-line lists;
- Markdown bullets and numbered lists;
- quoted and backtick-wrapped paths;
- fenced code blocks inside a longer AI response;
- `/` and `\` separators;
- relative and absolute paths;
- Unicode and spaces.

### Explicit project-root resolution

Relative paths are resolved only against a visible project root. XCC validates that root before applying the import and can reuse a reliable recent root as a suggested value. It never searches the whole disk for a matching suffix.

### Selected Files Review

Clicking the Source summary opens a review dialog with:

- project-root or `Mixed locations` state;
- stable relative display paths;
- multi-select removal;
- `Delete` keyboard removal;
- `Clear All`;
- transactional `Cancel` and `Apply Changes`.

### Predictable validation

The importer reports and separates:

- added files;
- already selected duplicates;
- missing paths;
- directories;
- unsupported files;
- absolute external files;
- invalid paths;
- relative paths that escape the chosen root.

Manual selection and pasted import share one ordered selection model. Repeated imports remain idempotent under Windows case-insensitive path semantics.

## Security and privacy

Pasted text is treated strictly as data. XCC does not execute commands, expand shell expressions, interpret globs, or upload the path list. Canonical resolution blocks `..` traversal outside the selected project root. Existing sensitive-context warnings and optional confirmation behavior remain unchanged.

## Compatibility

- Windows 10/11 x64
- CPython 3.13.x for source and development use
- no Python installation required for the packaged application
- settings and output formats remain compatible with v1.2.0

## Package

The official assets are:

```text
XCC-Context-Collector-v1.3.0-win64.zip
XCC-Context-Collector-v1.3.0-win64.zip.sha256
```

Extract the complete `XCC Context Collector` folder and keep the executable beside `_internal` and `VERSION.txt`.
