# XCC Context Collector v1.3.1

Version: 1.3.1  
Release date: 2026-08-17

## Summary

v1.3.1 is a responsive and DPI reliability patch for the v1.3.0 desktop experience. It keeps collection behavior unchanged while making the interface stable across constrained windows, wide displays, Windows scaling, monitor/work-area changes, and user-selected UI scale.

## Highlights

### Responsive workbench

- supported minimum remains `920×620`;
- width and height adapt independently;
- Collect reflows Source/actions and Last Run groups without recreating business widgets;
- wide logical viewports use a progressive Full-HD-referenced workbench instead of stretching cards indefinitely;
- Settings reflows `2 columns → 1` when constrained;
- History and About keep readable bounded surfaces;
- normal horizontal page scrolling stays disabled.

### Interface scale

Settings now provides:

```text
Auto (recommended)
90%
100%
110%
120%
125%
150%
```

`Auto` follows Windows/Qt. Explicit values apply a global XCC multiplier at startup, so a full restart is required after changing the setting.

The selector uses the XCC gold selection treatment and sizes itself to keep `Auto (recommended)` visible.

### DPI and monitor lifecycle

- raster and SVG presentation assets rerender for the active DPR;
- maximize/restore uses the current screen work area;
- restore geometry is clamped to the active work area;
- screen/work-area changes no longer leave stale geometry;
- tray/hotkey restore preserves the intended normal/maximized mode;
- responsive policy uses Qt logical geometry and never double-applies Windows DPI.

### Responsive dialogs

Paste Paths and Selected Files Review now fit the current screen work area, keep horizontal scrolling disabled, use vertical overflow when necessary, and remain usable with long paths or constrained height.

### Product polish

A subtle `X-SERIES` wordmark now appears at the right side of the footer. It is non-interactive, low contrast, DPI-aware, and included in packaged-asset validation.

## Reliability preserved

v1.3.1 does not change the v1.3.0 collection contracts:

- Paste Paths and guarded `Ctrl+V`;
- transactional Selected Files Review;
- exact source/Git payload preservation;
- staged/unstaged Git separation;
- explicit budget omissions;
- warning-only safety detection;
- background collection and cooperative cancellation;
- Last Run and metadata-only Runtime History;
- tray, native `Ctrl+Alt+X`, autostart, config recovery, and single instance.

## Compatibility

- Windows 10/11 x64
- CPython 3.13.x for source/development mode
- no Python installation required for the packaged build

Settings remain at `%USERPROFILE%\.xcc\config.json`.

## Package

```text
XCC-Context-Collector-v1.3.1-win64.zip
XCC-Context-Collector-v1.3.1-win64.zip.sha256
```

The binaries are not code-signed. Download only from the official repository and verify SHA-256 before running the archive.
