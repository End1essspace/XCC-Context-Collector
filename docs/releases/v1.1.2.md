# XCC Context Collector v1.1.2

Version: 1.1.2

XCC v1.1.2 was the stable baseline immediately preceding the v1.2.0 Context Integrity & Reliability release.

## Highlights

- Added the standalone **Project Tree** mode.
- Preserved Selected Files, Full Folder, and Git Changed Files workflows.
- Produced project structure without file payload sections.
- Continued to exclude built-in cache, dependency, IDE, and build directories.
- Distributed the Windows application as a portable x64 ZIP.

## Upgrade path

v1.2.0 retains the four v1.1.2 collection modes while adding source-fidelity guarantees, complete typed Git handling, structure-aware budgets, safety warnings, responsive background collection, result health, metadata-only history, and reproducible release validation.
